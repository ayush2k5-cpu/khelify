## Notes

1. **Firebase Blaze** — Start on free Spark plan. Upgrade to Blaze only when video uploads begin. Expected cost is minimal at MVP scale.
2. **Dartfish vs Hudl** — Dartfish is better value for individual biomechanics reference. Hudl is designed for team coaches, not individual scoring AI. Recommend Dartfish only for Phase 2.
3. **Figma** — Only 1 full seat needed (Lead / G uses it). Other team members can be added as "Collab Seats" at $5/month if needed.
4. **Claude + ChatGPT** — Both recommended because they have different strengths. Claude is better at long code context; ChatGPT is better for quick Q&A by team members.
5. **All prices are approximate** — Firebase and OpenAI API costs scale with usage and can vary significantly.
